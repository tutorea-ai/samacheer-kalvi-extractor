1. இயல் 1 — தமிழ்த்தேன்
    1. இன்பத்தமிழ்
    2. வளர்தமிழ்
    3. ஒலி பிறந்தது
    4. தமிழ் எழுத்துகளின் வகையும் தொகையும்
  2. இயல் 2 — இயற்கை இன்பம்
    1. ஏதிலிக்குருவிகள்
    2. சிறகின் ஓசை
    3. கிழவனும் கடலும்
    4. முதலெழுத்தும் சார்பெழுத்தும்
    5. திருக்குறள்
  3. இயல் 3 — கண்ணெனத் தகும்
    1. கல்வியைப் போற்று
    2. துன்பத்தை வெல்லும் கல்வி
    3. கல்விக்கண் திறந்தவர்
    4. நூலகம் நோக்கி
    5. மொழி முதல் எழுத்துகள்
