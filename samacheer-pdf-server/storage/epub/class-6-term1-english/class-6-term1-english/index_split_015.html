LANGUAGE CHECK POINT TABLE IS GIVEN:

The usage of many much, few, little, Each, Every, any, some is given with examples.

Don't Say

Say

Note

I cannot see much stars in the sky.

I cannot see many stars in the sky.

Use many with countable plural nouns. Use much with uncountable nouns.

I have little friends.

I have few friends.

Use few with countable nouns. Use little with uncountable nouns.

Every test contains twenty questions.

Each test contains twenty questions.

 

Each refers to an individual object or person. Every refers to a group of or people.

Is there any lemonade left?

 

Is there some lemonade left?

Any is used for questions and negatives. Some is used for positive.
